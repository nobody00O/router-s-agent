Your local scanning agent

This platform cannot see inside your home network by itself — the agent runs on your own machine, scans your own network, and reports results up to your dashboard here.

Your API key (keep this private — it authenticates the agent as you):

{{ api_key }}

Setup

  1. Download agent/local_agent.py from the project files.
  2. Install its one dependency: pip install requests scapy
  3. Edit the top of the file: set API_KEY to the key above, and SERVER_URL to this site's address.
  4. Run it with elevated privileges on your own network:
    sudo python3 local_agent.py

Only run this on a network you own or have explicit permission to scan.
